🚀 MartianHub 🌕
Explore real images from Mars, captured by NASA’s rovers.

📌 Overview
MartianHub is a web app that fetches and displays images taken by NASA’s Mars rovers. It provides a simple way to explore the Red Planet through high-quality photos from Curiosity, Perseverance, Opportunity, and Spirit.

🎯 How It Works
Open MartianHub in your web browser.

The app retrieves latest Mars images from NASA’s API.

Photos are displayed along with their capture dates.

Hover over images for a zoom effect.

✨ Features
✅ View real-time Mars images from NASA rovers
✅ Filter images by rover 


🛰️ Data Source
Powered by NASA Mars Rover API.
